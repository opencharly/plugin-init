# 2026.242.0556 — fix: add a root charly.yml so the candy CI gate is real

## Summary

Makes this repo's candy CI gate actually gate something.

Without a root `charly.yml` a plugin repo is **project-less**: charly scans **no candies at
all**, so the stock `charly box validate` step in `deploy.yml` exits 0 on any manifest —
including one with a malformed `plugin.providers` entry. The step has been asserting nothing
for this repo.

Two commits:

1. **Add the root manifest** — a four-line `discover:` block. The candy becomes scannable,
   the CUE schema gate applies, and the **stock** step starts working with no workflow change.
2. **Correct its schema stamp** — my first commit stamped `2026.240.1943` (current HEAD),
   but this repo's `deploy.yml` pins charly `v2026.238.1242`, whose maximum supported schema
   is `2026.232.0520`. That mismatch failed the `candy` workflow; the second commit stamps
   `2026.232.0520`, the value the peer candy repos already carry.

The file declares no entities of its own; it only tells charly where to look. Nothing under
`candy/` is touched — the schema requirement applies to the project **root** manifest only.

Refs opencharly/charly#459.

## How tested

Run against a binary built from **this repo's own pinned charly tag** (`v2026.238.1242`), not
a newer local build — using the wrong toolchain is exactly what caused the stamp mismatch
above.

**The manifest is accepted at the corrected stamp** (this repo, this branch):

```
$ charly box validate
(no output — exit 0)
```

**And the gate now bites.** Changing this repo's own `kind:init` provider entry in
`candy/plugin-init/charly.yml` to `notaclass:` — which previously passed at the repo root:

```
charly: error: command "validate": 2 validation errors:

candy "plugin-init": CUE schema: /home/atrawog/Sync/Atrapub/coder/claude/work/prwork/plugin-init/candy/plugin-init/charly.yml: candy "plugin-init": 2 errors in empty disjunction:
```

That failure is the point of the change: before the root manifest, that same malformed
manifest exited **0** here.
